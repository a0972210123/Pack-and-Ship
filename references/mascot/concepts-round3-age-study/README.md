# Telo Round 3 — 6–12 歲年齡梯度研究

本輪只測試「年齡感」，不取代目前角色設定書中的正式年齡。所有版本維持同一角色、同一甲片配置與簡化線條語言，主要改變頭身、四肢長度、臉部幼態程度與站姿自信度。

## 共用生成方向

- 灰階 2D 角色設計稿，白底、深灰輪廓、近白皮膚、冷灰甲片。
- 簡單線條與清楚剪影；只保留少量較大的甲片群，不做細碎鱗片、刮痕、排線或裝飾。
- 正面臉偏貓科、側面偏穿山甲；微尖上翹鼻吻、圓形大瞳孔、小型圓角三角耳。
- 直立怪獸型輪廓，但動作靈活快速；腿粗短有力，手腳各四趾。
- 額頭美人尖、臉頰無甲、克制的鬃甲、每側 2–3 片肩甲、背甲連續、腹部與手部無甲、腿外側半包覆、尾巴全覆甲。
- 每張包含主全身姿勢、側面頭部與蜷縮球形，用來檢查正側面辨識與滾動形態。
- 無服裝、配件、文字、品牌標誌或色票。

## 判讀限制

生成圖適合比較方向，不是最終設定稿。模型對相鄰年齡的差異可能表現得較細微；正式定案時應選定一個年齡區間，再以統一骨架重畫正、側、背三視圖，避免不同張之間的甲片數量與局部比例漂移。
