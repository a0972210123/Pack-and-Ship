## 共用生成條件

- 以 Round 3 的 6–7 歲版本作為幼齡連續性參考，並引用 Round 2 的友善臉型與幾何甲片版本。
- 保留 Telo 的臉部辨識：正面偏貓科、側面偏穿山甲、微尖上翹鼻吻、大圓瞳、小型圓角三角耳。
- 保留甲片配置：額頭美人尖、臉頰無甲、克制鬃甲、肩甲、連續背甲、腹部及手部無甲、腿外側半包覆、尾巴全覆甲。
- 維持灰階、簡單線條與少量大甲片，不加入衣物、配件、Logo、文字或表面細節。
- 每張包含主全身姿勢、側面頭部與蜷縮球形。

## 初步判讀

- **1 頭身**：輪廓集中、縮小後辨識力強，適合貼圖、App 圖示、周邊公仔與球形變身；代價是步態、手勢與「快速靈活」較難表演。
- **2 頭身**：仍然非常可愛，但能保留手腳、站姿、跳躍及滾動前的預備動作，較適合動畫與多場景敘事。
- **3 歲感**：最單純、被動而柔軟。
- **5 歲感**：好奇心與衝勁較明確，更接近目前設定中的「活潑靈動、單純愛分享」。

生成結果是方向草圖，尚未統一每張的甲片數量與精確骨架。正式採用前需要以選定比例重畫一致的三視圖與動作測試。
